# Интернет-магазин NIC

Учебный проект интернет-магазина на Spring Boot с аутентификацией, корзиной, заказами и отправкой писем через Яндекс.Почту.

## 🎯 Функционал

- 🛒 Корзина товаров
- 📦 Оформление заказов
- 🔐 Аутентификация и авторизация (JWT)
- 📧 Отправка подтверждений на почту
- 📊 Категории и каталог товаров

## 🎯 Инструкция по сборке
1. Установите Docker Desktop
2. Склонируйте репозиторий:
    https://github.com/tatyana2901/Internet_shop_NIC.git
   
3. Соберите проект
4. Запустите приложение с базой данных: docker-compose up --build
5. Откройте приложение в браузере: http://localhost:8080
